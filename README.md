### 사용 방법
1. **파일 선택하기** 버튼을 클릭하여 이름을 바꿀 파일들을 선택
2. **새 파일 이름** 칸에 원하는 키워드를 입력
3. **정렬 기준** 드롭다운 메뉴에서 원하는 순서를 선택
4. **이름 변경 시작** 버튼을 누르면 작업이 완료

## Renamer

선택한 여러 이미지 파일의 이름을 한 번에 규칙적으로 변경해주는 Python 기반 GUI 프로그램입니다. 
편의를 위해 윈도우 고해상도(DPI) 지원으로 선명한 UI를 제공하며, 다양한 정렬 옵션을 지원합니다.

### 주요 기능
*   **멀티 포맷 지원**: `png`, `jpg`, `jpeg`, `webp` 등 다양한 이미지 확장자 지원
*   **다양한 정렬 옵션**:
    *   기존 이름 기준 (오름차순/내림차순)
    *   파일 수정 시간 기준 (과거순/최신순)
*   **사용자 친화적 UI**: 
    *   파일 탐색기를 통한 자유로운 파일 선택
*   **안전한 이름 변경**: 파일 인덱싱(`_1`, `_2`...)을 통해 깔끔한 파일 정리 가능

### 시작하기

#### 요구 사항
*   Python 3.x

#### 실행 방법
코드를 실행하거나 터미널에서 아래 명령어를 실행합니다.
   ```bash
   python main.py
   ```
exe 파일도 만들어놨습니다.
